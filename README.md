# WILDROOT · 태양의 그늘

70스테이지를 탐험하는 판타지 액션 플랫폼 게임입니다. 가면별 전투 방식과 3단계 진화, 장비·시너지, 보스전, 루네와의 동행 퍼즐을 제공합니다.

**[게임 플레이](https://hsjun519.github.io/WILDROOT/)** · 현재 버전 3.9.1

## 조작

| 동작 | 키 |
|---|---|
| 이동 / 사다리 | 방향키 |
| 점프 | ↑ 또는 Space |
| 기본 공격 | Z |
| 회피 | X |
| 패링 | C |
| 스킬 1 / 2 / 3 | A / S / D |
| 상호작용 | V · 가면 획득은 2초 유지 |
| 보상 분해 | G 2초 유지 |
| 가면 교대 | Q |
| 가방 / 성장 / 역사 | B / N / H |
| 동행 퍼즐 인물 교대 | Tab |
| 일시정지 | Esc |

첫 교전을 마치면 가면 상자가 한 번 확정으로 등장합니다. 상자를 열고 V를 2초 눌러 장착하세요. 진행 기록은 사용하는 브라우저에 저장됩니다. 다른 주소나 브라우저로 옮길 때는 게임 내 저장 내보내기/불러오기를 이용하세요.

## 로컬 실행

Node.js 18 이상에서 의존성 설치 없이 실행할 수 있습니다.

    npm start

http://localhost:4173/WILDROOT/ 에서 실행됩니다. 정적 파일 호스팅만 필요하고 서버 계정·API 키가 필요하지 않습니다.

    npm test

이 검사는 파일 크기, 이미지 해시와 참조 누락을 검사합니다.

## 파일 구성

- index.html: 게임 화면과 메뉴
- src/game.js: 게임 로직
- styles/game.css: UI 스타일
- assets/: 원본과 동일한 그림 및 해시 목록
- docs/: 배포 검증 기록

단일 HTML에서 그림·스타일·코드를 분리했습니다. 분리 전후의 HTML을 다시 합쳐 원본과 동일한 것을 검사했으며, GitHub Pages의 /WILDROOT/ 하위 경로에서 실행되도록 상대 경로를 사용합니다. main 브랜치의 루트가 Pages 배포 소스입니다.

게임 그림은 이 프로젝트를 위해 생성한 리소스이며, 참고 게임의 이미지나 첨부 스크린샷은 이 저장소에 포함하지 않았습니다. 공개 저장소 등록 자체로 별도의 오픈소스 재사용 라이선스를 지정하지는 않았습니다.
